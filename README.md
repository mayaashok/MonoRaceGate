# MonoRaceGate

Drone Racing Gate Dataset with Precise Corner Labels



## Installation

```make```


## Labels

 - corner.csv files contain the ```x``` and ```y``` coordinates of the inner gate corners in the sequence: Top-Left, Top-Right, Bottom-Right, Bottom-Left.
